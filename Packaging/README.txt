ScenePaint v0.2 — source-built distribution

Application code and build scripts are MIT-licensed; see LICENSE and NOTICE.md.
Model weights and runtime dependencies retain their own licenses and notices.
Requires macOS 14+ and Apple Silicon. This build is ad-hoc signed, not notarized.

Models and a relocated runtime are included by the packager. Inference runs
locally, with no paid service, account, API key, or app usage quota.

A source build opens blank unless its distributor supplies an optional demo.
The public creator demo and branding are separate from the MIT code archive.

Save projects as .scenepaint. Freeze/Bake retain source layers and Motion data;
Unfreeze All restores nested groups. Exports are rendered images/videos, not
editable projects. Use a lower preview size for heavy artwork and a separate
higher output size when exporting. Drawing pauses playback.

For detailed architecture, controls, setup, licensing and checks, read README.md
in the source release and the Third-party notices included with this app.
